**Partially-known environment**:
    In penetration testing, a partially-known environment (gray-box environment) means the tester has some knowledge of the target (e.g., network diagrams, API documentation) but not complete details. This balances realism and efficiency, allowing focused testing without the full insider view of a white-box text.

Passive recon is an information-gathering technique (using public sources).

A **Tabletop Exercise** is a discussion-based session where the incident response team walks through simulated incident scenarios to validate their response plan, identify gaps, and clarify roles and responsabilities. Unlike live drill or penetration tests, tabletop exercises do not involve actual system testing, making them a low-cost, low-risk way to improve incident preparedness.

**Endpoint Detection and Response (EDR)** solutions provide continuous monitoring of endpoint activities, behavioral analysis to detect suspicious patterns, and automated response capabilities such as isolating infected endpoints. EDR goes beyond traditional signature-based antivirus by using behavioral analytics and machine learning to detect advanced threats that evade traditional detection methods.

**Change Management** is the formal process for requesting, assessing, authorizing, shceduling, implementing, validating, and documenting production changes. The appropriate change authority depends on the organization's process; higher-risk changes also need testing and a workable backout plan.
